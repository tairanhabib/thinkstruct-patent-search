# Multilingual evaluation

Generated by `python scripts/evaluate_multilingual.py`.

- 100 patents exist in English (original), German and Chinese (machine translated copies made by `scripts/make_parallel_set.py` with opus-mt, greedy decoding).
- Query: the first claim of each patent, in English, as stored (not the title, not the abstract).
- Candidates: abstracts and description paragraphs only. Claims are excluded, so a patent cannot be found through the query text itself.
- Right answer: the same patent, in the language of the row.
- Embedding model: `intfloat/multilingual-e5-small`. Recall at k is the share of queries whose patent is in the top k. MRR is mean reciprocal rank.
- The interval is a 95% paired bootstrap interval on the difference in MRR against English, same method.
- "Shared space" is one query vector for all languages. "Query translated" scores each passage against the query translated into that passage's language (the default in `search()`).

**Read the "query translated" rows for German and Chinese as an upper bound.** The German and Chinese copies were produced by the same opus-mt models that then translate the query, so query and document share wording more than they would with real foreign patents. The "Foreign query, English patents" table further down is less affected: there the documents are the original human-written English, though the query is still a machine translation of that same patent's claim.

## What query translation costs per query

Translating one claim-length query (median 667 characters) into 2 languages (de, zh) with greedy decoding:

| | Median | Slowest |
| --- | --- | --- |
| Not cached, models already loaded (10 queries, one at a time) | 1218 ms | 2114 ms |
| Cache hit: the translation step inside `search()` in the tables above | 0.06 ms | 1.46 ms |

All queries were translated in bulk before the tables above were computed: 265,822 characters in 48 s (5,511 characters per second).

## Why the shared space fails: language bias

Cosine similarity between abstracts. If the space were truly shared, a patent and its own translation would be closer than two different patents.

| Pair | Mean similarity | 99th percentile |
| --- | --- | --- |
| English abstract and a different English patent's abstract | 0.831 | 0.900 |
| English abstract and the same patent in German | 0.851 | 0.894 |
| Share of different English abstracts that score above the patent's own German copy | 27.5% | |
| English abstract and the same patent in Chinese | 0.809 | 0.854 |
| Share of different English abstracts that score above the patent's own Chinese copy | 76.2% | |
